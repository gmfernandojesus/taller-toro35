# Compatibilidad con Workshop Tool 3.0

La versión **3.0** de Workshop Tool salió con esta dirección grabada dentro
del programa para buscar actualizaciones. Como la dirección va compilada en
el `.exe`, no se puede cambiar a distancia: si aquí no hay nada, esas
instalaciones dicen para siempre *"no se ha podido comprobar"*.

Este repositorio existe solo para eso: que las instalaciones de la 3.0 se
enteren de que hay versión nueva y puedan actualizarse.

**A partir de la 3.1 los programas leen de
[`actualizaciones`](https://github.com/gmfernandojesus/actualizaciones)**,
que es el sitio bueno.

## Mientras exista algún cliente con la 3.0

Al publicar una versión nueva hay que actualizar `version.json` **aquí
también**, no solo en `actualizaciones`.

Cuando no quede ningún taller con la 3.0, este repositorio se puede borrar.

## Descargas

En [Releases de actualizaciones](https://github.com/gmfernandojesus/actualizaciones/releases/latest).
